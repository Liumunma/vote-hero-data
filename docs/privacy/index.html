隱私權政策

投票勇者 Vote Hero TW · 更新日期：2026-10-30

適用範圍與聯絡方式

本政策適用於投票勇者 iOS App 及本支援網站。開發者：CHIA LIN WU。隱私問題、資料更正或支援請來信 support@urpig.com。

存在手機上的資料

App 不需要註冊或登入。預言紀錄、音效偏好、廣告頻率紀錄與下載快取保存在裝置上；App 不會將你的預言上傳給開發者，也不彙整其他使用者的選擇。移除 App 會刪除其本機資料；若裝置使用系統備份，備份由你的 Apple 設定管理。

廣告與同意

App 使用 Google AdMob 顯示橫幅與插頁廣告，並使用 Google UMP 處理適用地區的廣告同意。Google 的 SDK 可能處理 IP 位址、大致位置、裝置識別資訊、廣告互動及診斷資料，用於廣告投放、衡量與防止詐騙。是否可用識別資訊受裝置權限及同意狀態影響；App 目前不顯示 ATT 追蹤授權提示。

在需要提供隱私選項的地區，可從 App「說明」中的「廣告隱私設定」管理可用選項。詳見 Google 合作夥伴資料使用說明及 Google 隱私權政策。

網路下載與網站

App 會從 GitHub Pages 下載公開候選人與新聞資料，開票時也可能從 GitHub API 下載結果。這些連線及造訪本網站會讓網路服務提供者收到 IP 位址、請求時間等一般連線資料；資料快取與記錄依提供者政策處理。本網站使用 GitHub Pages 託管，網域由 Cloudflare 管理。

點選來源連結會前往新聞媒體網站，其資料處理依該網站規範。若你寄信或提交 GitHub Issue，我們會收到你主動提供的內容與聯絡資料，用於處理請求；請勿在公開 Issue 提供私人資料。

政策變更

服務或資料處理方式變更時，本頁會更新並標示日期。你可透過上述支援信箱提出問題。
